## Classification and scope

- **A — correct/currently accepted with zero numeric offset:** `$26`, `$27` (limited visual check), `$28`. Zero is an explicit result, not an absence of audit.
- **B — GameMaker presentation policy already accepted:** `$10`, `$21`, and `$1B`'s bottom-aligned dynamic crop.
- **C — visually suspect / needs Windows or emulator comparison:** `$09` is **FINAL VISUAL REGISTRATION UNRESOLVED** after `+8` failed Windows acceptance; `$18` remains pending a meaningful comparison.
- **D — source or mapping not sufficiently recovered:** none of the audited classes is placed here solely because it uses a bespoke or zero-offset presentation path.

`$05` and `$0F` are generated transient/replacement effects, not ordinary THZ1 raw-placement instances, so they are outside this placement-anchor table. Terrain-derived rings remain a separate 142-record terrain-quadrant class and do not use this adapter API.

## Acceptance discipline

No canonical coordinate changed in this pass. `$09` remains at `(0,0)` after the `+8` experiment failed Windows acceptance; final registration is unresolved and no replacement value is guessed. `$10`, `$18`, and `$21` retain their existing named numeric presentation policies. `$1B` retains its established bottom-aligned crop. `$26`, `$27`, and `$28` remain at the currently accepted `(0,0)` numeric offset.
